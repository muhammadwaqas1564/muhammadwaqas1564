### 📁 Showcase Repositories

#### 🏥 1. [Medical-Images-Classification](https://github.com/muhammadwaqas1564/Medical-Images-Classification)
An explainable medical image diagnosis framework integrating deep learning backbones and quantitative saliency map verification engines for verifiable visual diagnostic attribution.
* **Tech Stack:** `PyTorch`, `Torchvision`, `DenseNet`, `Grad-CAM`, `OpenCV`
* **Key Features:** Saliency map generation, dual-branch decoder architectures, clinical Trust Index scoring.

#### 🚗 2. [Real-Time-License-Plate-Recognition-System](https://github.com/muhammadwaqas1564/Real-Time-License-Plate-Recognition-System)
An end-to-end web-based License Plate Recognition (ALPR) system built for automated toll management, vehicle tracking, and revenue monitoring.
* **Tech Stack:** `Python`, `YOLO`, `OpenCV`, `CRNN / EasyOCR`, `Streamlit / FastAPI`
* **Key Features:** Low-latency inference, automatic character segmentation, real-time bounding box detection.

#### 📹 3. [AI-Video-Summarization-and-Highlights-Generation](https://github.com/muhammadwaqas1564/AI-Video-Summarization-and-Highlights-Generation)
An AI pipeline designed to automatically summarize long videos and extract high-interest keyframes using deep spatio-temporal representations.
* **Tech Stack:** `Python`, `PyTorch`, `OpenCV`, `Jupyter Notebook`, `Transformers`
* **Key Features:** Automated keyframe selection, scene transition detection, highlight video generation.

#### 🛡️ 4. [Cyber-Threat-Detection](https://github.com/muhammadwaqas1564/Cyber-Threat-Detection)
A machine learning system for network traffic analysis, packet flow feature extraction, and real-time cyber threat anomaly classification.
* **Tech Stack:** `Python`, `scikit-learn`, `Pandas`, `Jupyter Notebook`, `Imbalanced-learn`
* **Key Features:** Imbalanced data handling, high-recall anomaly detection, threat probability scoring.

#### 🛒 5. [Product-Detection-in-Retail-Environments](https://github.com/muhammadwaqas1564/Product-Detection-in-Retail-Environments)
A computer vision object detection model tailored for retail shelf management, product recognition, and automated visual stock inventory tracking.
* **Tech Stack:** `Python`, `PyTorch`, `YOLOv8`, `OpenCV`, `Albumentations`
* **Key Features:** Fine-grained object classification, bounding box localization under occlusion and varied lighting.

#### 🅿️ 6. [Smart-Vehicle-Parking-System](https://github.com/muhammadwaqas1564/Smart-Vehicle-Parking-System)
An automated computer vision framework that processes parking surveillance feeds to track spot occupancy in real time and optimize parking distribution.
* **Tech Stack:** `Python`, `OpenCV`, `PyTorch`, `NumPy`
* **Key Features:** Parking spot coordinate mapping, live status monitoring, lightweight edge deployment.
